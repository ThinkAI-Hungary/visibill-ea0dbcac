# AI Instructions — Visibill Project

## Zero-Flicker Rule (Critical)

All interactive elements (buttons, triggers, toggles) MUST follow these focus rules:

1. **Never use `focus:ring-*`** — use `focus-visible:ring-*` instead.
2. **Always add**: `outline-none ring-0 focus:ring-0 focus-visible:ring-1 focus-visible:ring-ring`
3. **Sheet/Dialog close**: always add `onCloseAutoFocus={(e) => e.preventDefault()}` to `SheetContent` and `DialogContent` to prevent focus flash on the trigger button.
4. **Popover triggers**: same `outline-none ring-0` treatment.

This ensures mouse clicks never leave a visible focus ring, while keyboard navigation (`Tab`) still shows the `:focus-visible` ring for accessibility.
