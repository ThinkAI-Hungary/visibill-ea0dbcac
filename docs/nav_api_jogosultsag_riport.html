3 Technikai Háttér & Gyökérok-elemzés

🔍 Miért működik a kimenő és miért bukik el a bejövő ág?
A NAV Online Számla 3.0 API specifikációja szerint a technikai felhasználóhoz két önálló jogosultsági csoport tartozik:

1. Számlák kezelése (Manage Invoices): Lehetővé teszi a cég által kibocsátott saját számlák beküldését és lekérdezését (kimenő irány). Ez mindkét cégnél be van jelölve.
2. Számlák lekérdezése (Query Invoices): Kizárólag ez teszi lehetővé a partnerek által a cég adószámára kiállított szállítói számlák adatainak letöltését (bejövő irány). Ez a jogosultság jelenleg hiányzik mindkét technikai felhasználónál.
