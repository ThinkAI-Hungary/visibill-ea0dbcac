1. Környezet és konfiguráció

Technológiai stack

Unit test runnervitest — Vite-natív, jsdom környezet
Assertion könyvtár@testing-library/react + @testing-library/jest-dom

4. Megosztott E2E helper HELPER

A tests/helpers.ts közös segédfüggvényeket biztosít az összes E2E teszthez.

Exportált függvények

login(page)Stabil bejelentkezés — input[type="email/password"] + button[type="submit"] locatorokkal. Vár a loading spinner eltűnésére és az Irányítópult link megjelenésére.
navigateTo(page, name)Sidebar navigáció getByRole("link", { name }) selectorral — elkerüli a strict mode violation-t.
waitForAppReady(page)Vár a full-page loading spinner (.fixed.inset-0.z-[9999]) eltűnésére.
TEST_EMAILExportált konstans — .env.local / process.env / hibaüzenet.
TEST_PASSWORDExportált konstans — mint fent.

Env betöltés logikája

A loadEnvLocal() függvény ESM-kompatibilis: import.meta.url → fileURLToPath → dirname path feloldással tölti be a .env.local fájlt. Szükséges változók hiánya esetén azonnal throw Error-rel leáll, egyértelmű hibaüzenettel.

5. Futtatási parancsok

# ─── Unit tesztek (Vitest) ─────────────────────────── npm run test # Összes unit teszt futtatása npx vitest run --reporter=verbose # Részletes kimenet npx vitest --ui # Vitest UI (interaktív) # ─── E2E tesztek (Playwright) ──────────────────────── npm run test:e2e # Összes E2E teszt npx playwright test --ui # Playwright UI (vizuális debug) npx playwright test auth-security # Egyetlen fájl futtatása npx playwright test --update-snapshots # Screenshot baseline generálás npx playwright show-report # HTML riport megnyitása

⚠️ Fontos megjegyzések

Screenshot baselineAz első futtatáskor a toHaveScreenshot() assertek FAIL-elnek. Futtasd --update-snapshots flag-gel a referencia képek létrehozásához.
Production buildA data-testid attribútumok automatikusan eltávolítódnak a production buildből (vite-plugin-react-remove-attributes).
Toast triggerAz E2E tesztek a window.__visibillTestToast() segítségével triggerelnek valódi Radix toastokat. Ez a use-toast.ts-ben van exportálva a window-ra.
