# P-039: Globális Keresés

**Status:** Decided  
**Category:** Keresés

**Question:** Van-e globális keresés ami számlák, partnerek, tranzakciók között keres?

**Decision:** Nincs globális keresés. Oldalankénti szűrők elegendőek.

**Rationale:** Az oldalankénti szűrők lefedik a keresési igényt a jelenlegi user bázisnak. Cmd+K globális keresés bevezetése akkor lesz aktuális ha a user feedback indokolja és a user bázis elég nagy ahhoz hogy a fejlesztési ráfordítás megtérüljön.
