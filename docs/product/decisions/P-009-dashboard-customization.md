# P-009: Dashboard Testreszabhatóság

**Status:** Decided  
**Category:** Dashboard & Navigáció

**Question:** Tud-e a felhasználó widgeteket átrendezni, elrejteni, vagy személyre szabni a dashboardot?

**Decision:** Nincs testreszabhatóság. A meglévő preferences (valuta, bruttó/nettó, collapsible szekciók) elegendőek.

**Rationale:** Fix elrendezés konzisztens és egyszerű. Nincs karbantartási teher. Ha user feedback alapján igény merül fel, widget show/hide toggle-ök bevezethetők.
